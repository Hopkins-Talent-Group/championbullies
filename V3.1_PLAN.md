# v3.1 Plan: Modal Reservation Flow (E-commerce Product Page Style)

## Objective
Replace the current "scroll to contact form" approach with a **modal-based step-by-step reservation wizard** — similar to e-commerce product pages (e.g., Apple, Nike, Tesla configurators).

---

## Current State (v3.1)

### Implemented (Phases 1-5):
- **Context + Types** (`src/context/ReservationContext.tsx`) — React context + useReducer for multi-step state, open/close actions, field updates via `setField`
- **Validation Schemas** (`src/lib/validation.ts`) — Zod schemas for all 4 steps (puppy, contact, living, agreement) with type inference
- **Step Components** (`src/components/ReservationSteps/`) — 4 standalone components:
  - `Step1-Puppy.tsx` — Display puppy details read-only from clicked card
  - `Step2-Contact.tsx` — Contact form: name, email, phone with Zod validation + react-hook-form
  - `Step3-Living.tsx` — Living situation: home type, yard, other pets, children ages, hours alone
  - `Step4-Agreement.tsx` — Health guarantee + spay/neuter acknowledgment + $500 deposit confirmation
- **Modal Component** (`src/components/ReservationModal.tsx`) — Portal modal with:
  - Stepper progress bar showing Puppy → Contact → Living → Agreement
  - Keyboard ESC close, backdrop click to close
  - Next/Prev navigation between steps
  - "Reserve" button on final step
  - Integration with Gallery via `useReservation` context
- **Gallery Integration** (`src/components/Gallery.tsx`) — "Reserve Now" button opens modal with correct puppy pre-loaded via context
- **Build Status** — Compiles successfully (TypeScript errors exist in hover styles but build passes)

### Pending / Future:
- Polish: Tailwind class-based hover styles instead of inline `&:hover`
- Mobile-bottom sheet UX for < 640px
- localStorage persistence of form data across refresh/close
- API integration: `POST /api/reservations` + Stripe PaymentIntent
- Admin dashboard for reservation approval/denial
- Success toast/clear state on submit

## Target State (v3.1)

### 1. Modal Component (`src/components/ReservationModal.tsx`)
```tsx
// Features:
- Full-screen / centered modal with backdrop blur
- Stepper/progress indicator (Step 1 of 4)
- Keyboard accessible (ESC to close, Tab trap)
- Portal-rendered (ReactDOM.createPortal)
- Animations: fade + slide up (Framer Motion or CSS)
```

### 2. Step-by-Step Flow (4 Steps)

| Step | Title | Fields | Validation |
|------|-------|--------|------------|
| 1 | **Puppy Details** | Puppy name, breed, price (read-only), deposit amount | Auto-filled from clicked card |
| 2 | **Contact Info** | Name*, Email*, Phone | Email format, required |
| 3 | **Living Situation** | Home type (house/apt), yard (Y/N), other pets, children ages, hours alone/day | Required selects |
| 4 | **Agreement & Deposit** | Health guarantee acknowledgment, spay/neuter agreement, deposit payment ($500), payment method | All checkboxes required |

### 3. Data Model
```ts
interface ReservationData {
  // Step 1
  puppyKey: string;
  puppyName: string;
  breed: string;
  price: string;
  deposit: "$500";
  // Step 2
  name: string;
  email: string;
  phone: string;
  // Step 3
  homeType: "house" | "apartment" | "other";
  hasYard: boolean;
  otherPets: string;
  childrenAges: string;
  hoursAlone: string;
  // Step 4
  healthGuaranteeAck: boolean;
  spayNeuterAck: boolean;
  depositPaid: boolean;
  paymentMethodId?: string; // Stripe PaymentMethod
}
```

### 4. State Management
- **Local state in modal** (useReducer for complex multi-step)
- **Persist to localStorage** on each step (survive accidental close)
- **Clear on successful submission**
- **Context** (`ReservationContext`) for access from Gallery cards

### 5. API Integration (Future)
- `POST /api/reservations` → creates pending reservation
- Stripe PaymentIntent for $500 deposit
- Webhook confirms → sends PDF contract + welcome email
- Admin dashboard to approve/deny

### 6. UX Details
- **Progress bar** at top: `Puppy → Contact → Home → Confirm`
- **Back/Next** navigation (disabled until valid)
- **Summary sidebar** (desktop) showing puppy photo + price
- **Micro-copy**: helpful hints, not errors ("We ask this to ensure best match")
- **Mobile-first**: full-screen bottom sheet on < 640px

### 7. Accessibility
- `role="dialog" aria-modal="true" aria-labelledby="modal-title"`
- Focus trap within modal
- Restore focus to trigger button on close
- ARIA live regions for step changes
- Semantic `<form>` per step
